Cue Script Reference
Timing
wait HH:MM:SS:FF          pause (timecode @ 24fps)
Set Values (instant)
set attack NNNms          (also: decay, release)
set sustain N             0–10
set gate NNNms
set cutoff N              0–10
set amount N              0–10
Transition (smooth, ease in/out)
transition <param> <value> HH:MM:SS:FF
params: attack decay sustain
        release gate cutoff amount
(run in parallel; use wait to sequence)
